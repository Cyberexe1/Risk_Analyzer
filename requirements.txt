# WHAT USED TO BE HERE
# --------------------
# This replaces requirements-serve.txt (runtime only) and requirements-dev.txt
# (which pulled in the former and added scikit-learn). The split existed so the
# serving container could avoid installing scikit-learn, pytest and httpx. With one
# file, `docker build` now installs all three -- see the note in the Dockerfile. If
# image size or attack surface matters more than having a single file, the split is
# the thing to restore.
